Chowder for Ubuntu and Debian

Chowder is a desktop interface for ClamAV from Clarity Soft.

Test release: version 0.1.2-test is for evaluation and is not a signed production release.

Install

Open Terminal and paste this one line:

curl -fsSL https://advtuning.github.io/chowder-apt/install.sh | bash

The installer adds the signed Chowder repository and installs Chowder, ClamAV and its signature updater.

Supported packages

64-bit Intel/AMD (amd64) and 64-bit ARM (arm64).
